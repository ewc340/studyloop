committed so that cloud runs of the AFK loop — which can't see a developer's `~/.claude/skills` — have them:

- `implement`, `tdd`, `code-review`, `pr`, `codebase-design` (referenced by `tdd`)

`pr` also carries its own `CREDITS.md`. To update, re-copy from the upstream repo.
